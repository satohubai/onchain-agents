## Install lines

Where a project publishes one, as recorded in its deploy spec:

- **TradingAgents** — `git clone https://github.com/TauricResearch/TradingAgents.git`
- **ElizaOS** — `bun add -g elizaos@beta`
- **Fetch.ai uAgents** — `pip install uagents`
- **Olas (Autonolas)** — `pip install open-autonomy[all]`
- **OpenClaw** — `npm install -g openclaw@latest`
- **Hermes Agent** — `pip install hermes-agent   # PyPI (Python 3.11–3.13)`
- **Almanak** — `pipx install almanak`
- **OpenAI Codex** — `npm install -g @openai/codex`
- **Claude Code** — `npm install -g @anthropic-ai/claude-code`
- **Lucid Agents** — `bunx @lucid-agents/cli my-agent`
- **OpenServ** — `npm install @openserv-labs/sdk`
- **Arbitrum Vibekit** — `npx -y @emberai/agent-node@latest init`
- **IronClaw** — `curl --proto '=https' --tlsv1.2 -LsSf https://github.com/nearai/ironclaw/releases/latest/download/ironclaw-installer.sh `
- **IntentKit** — `pip install intentkit`
- **GAME SDK (Virtuals Protocol)** — `pip install game_sdk`
- **Grok CLI** — `npm install -g @vibe-kit/grok-cli   # binary: grok`
- **Starknet Agentic** — `npx @starknetfoundation/create-starknet-agent@latest`
- **LumoKit** — `cp .env.example .env`
- **Snak (Starknet Agent Kit)** — `git clone https://github.com/kasarlabs/snak.git`
- **Injective Agents** — `git clone https://github.com/InjectiveLabs/iAgent.git`
- **Ping Agent Kit** — `npm install ping-agent-kit`
- **Warden Protocol** — `npm install @wardenprotocol/agent-kit @langchain/langgraph-sdk`
- **Daydreams** — `npm install @daydreamsai/core @ai-sdk/openai zod`
- **Cambrian Agent Kit** — `cp .env.example .env`
- **Wayfinder** — `git clone https://github.com/WayfinderFoundation/wayfinder-paths-sdk`
- **listen (DeFAI toolkit)** — `sudo apt install protoc build-essential pkg-config libssl-dev`
- **Manus** — `No self-host install — Manus is a hosted product. Sign up at https://manus.im for access.`
