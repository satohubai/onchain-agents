## Deploy spec

```sh
npx @dexterai/opendexter setup
```

- **Entry:** Setup command creates a local wallet and wires OpenDexter into Claude Code, Cursor, Codex, Windsurf, Gemini CLI, or VS Code; tools: x402_wallet, x402_search, x402_check, x402_fetch, x402_access, x402_settings
- **Runtime:** Node.js (npx setup) or hosted MCP
- **Requires:** Setup creates a wallet on your machine (local key custody risk); hosted mode instead uses a funded session wallet
