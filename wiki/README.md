# Wiki source

The seven pages of https://github.com/satohubai/onchain-agents/wiki.

Five of them are prose, written once and versioned here so a wiki edit has a
reviewable origin. Two are **derived and not kept here** — `Standards.md`
(counted from `data/index.json`) and `Glossary.md` (text from
`data/glossary.json`) are regenerated by `scripts/wiki-sync.mjs` and pushed
weekly by `.github/workflows/wiki-sync.yml`.

`wiki-sync.mjs` seeds a page from this folder only when it is **missing** from
the wiki, so an edit made in the wiki UI is never clobbered by the weekly job.

## One-time setup

GitHub does not create the wiki's git repository until a first page exists, and
there is no API for it. Create any page once at
https://github.com/satohubai/onchain-agents/wiki/_new — then:

```sh
git clone https://github.com/satohubai/onchain-agents.wiki.git
node scripts/wiki-sync.mjs --wiki onchain-agents.wiki
cd onchain-agents.wiki && git add -A && git commit -m "wiki: seed" && git push
```

After that the weekly job keeps the two derived pages current on its own.
